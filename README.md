# About the Project

This was my **first full completed HTML and CSS web development project**. It was created as a personal project to practice and apply the fundamental concepts I had learned while studying web development.

The project is a frontend recreation of the **YouTube homepage**, focusing on reproducing the general layout, navigation, video grid, sidebar, search bar, thumbnails, channel information, and interactive hover elements.

Although it is not a functional replacement for YouTube, the project allowed me to gain practical experience recreating a complex website layout from scratch using HTML and CSS.

# Project Overview

This project recreates the frontend layout of a YouTube-style homepage.

The page contains a fixed header with a search bar and navigation icons, a responsive sidebar, and a video grid containing video thumbnails, titles, channel information, view counts, and upload times.

The project also includes hover tooltips for various interface elements and channel profiles. CSS media queries are used to change the layout depending on the size of the browser window.

The project was built entirely using **HTML5 and CSS3**, without JavaScript or frontend frameworks.

# Design

The project was designed to closely resemble the general appearance and structure of the YouTube homepage.

The layout uses **CSS Grid** for the video section, **Flexbox** for the header and navigation elements, and **media queries** to adjust the number of video columns and sidebar layout at different screen widths.

Hover tooltips were also implemented to make the interface feel more similar to a modern video-sharing platform.

# Purpose

The main purpose of this project was to put my HTML and CSS knowledge into practice by recreating a relatively complex website interface.

As my **first full completed HTML/CSS project**, it was an important step in learning how individual HTML and CSS concepts could be combined to create a complete webpage rather than isolated exercises.
